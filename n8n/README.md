# n8n Workflow Configurations

This directory contains n8n workflow JSON exports for automated data ingestion.

## Planned Workflows

1. **daily-news-ingestion.json** — Scrape BD news RSS feeds daily
2. **factcheck-sync.json** — Sync fact-check databases
3. **source-reputation-update.json** — Update source reliability scores

## Setup

Import these JSON files into your n8n instance at `http://localhost:5678`.
